💡 KEY TAKEAWAYS

Engineering Takeaways & Lessons

What I learned building a modern, resilience-first portfolio suite.

1️⃣ Design for Fallbacks
Never rely 100% on external APIs. Always provide robust local mock fallbacks so the UI renders instantly regardless of API status.
2️⃣ Live Data API Orchestration
Combining multiple third-party APIs (TMDb, Steam, Supabase) enriches static projects into dynamic media hubs.
3️⃣ AI as a Native Component
AI shouldn't be an afterthought. Integrating a domain-trained AI widget turns a portfolio into an interactive hiring assistant.
